# 项目技术栈

本文件定义项目各层的技术选型与版本约束。引入清单外的新依赖需评估并更新本文件。

## 后端技术栈

| 领域 | 选型 | 版本/说明 |
| --- | --- | --- |
| 运行时 | JDK | 21（LTS） |
| 框架 | Spring Boot | 3.x（基于 Jakarta EE 命名空间） |
| 数据库 | MySQL 8.x | InnoDB 引擎，字符集 `utf8mb4`，默认排序规则 `utf8mb4_0900_ai_ci` |
| 对象映射 | MyBatis-Plus | 分页、乐观锁、自动填充均使用其内置能力 |
| 缓存 | Redis 协议兼容的 KV 缓存 | Java 客户端使用 Jedis |
| 对象存储 | S3 协议兼容存储（MinIO、RustFS 等） | 使用 AWS S3 SDK 访问 |
| 接口文档 | Knife4j（Swagger） | 所有接口必须有中文说明 |
| 日志门面 | SLF4J | 代码中统一使用 |
| 日志实现 | Logback | 其他日志框架统一转接为 Logback |
| 安全框架 | 不引入 Spring Security | 采用自定义 Filter 链，见[后端API权限控制规范](后端API权限控制规范.md) |
| Filter 实现 | `jakarta.servlet.Filter` 接口 | 优先使用原生接口，避免框架绑定 |

| 领域 | 选型 | 说明 |
| --- | --- | --- |
| 语言 | Python | 3.12 |
| 框架 | FastAPI | 提供 HTTP 推理接口 |
| 深度学习 | PyTorch | 推理使用 CPU 或 GPU |
| 模型格式 | ONNX / TorchScript | 由模型服务加载 |
| 接口约定 | `POST /predict` | 接收 multipart 文件，返回 JSON（分级、置信度、各类别概率） |

## 依赖引入原则

1. **最小依赖**：优先使用 JDK 与 Spring Boot 自带能力，避免引入功能重叠的库。
2. **统一版本**：依赖版本在 BOM 模块（`{app}-dependencies-bom`）中统一声明，子模块不得自行指定版本。
3. **安全优先**：安全能力通过自定义 Filter 实现，非必要不引入 Spring Security。
4. **日志归一**：任何第三方库的日志（JCL、log4j、JUL）必须通过桥接器转接至 Logback。
5. **兼容性**：涉及数据库、缓存、对象存储的依赖，优先选择遵循标准协议（SQL 标准、Redis 协议、S3 协议）的实现，保证可替换性。

## 数据库选型说明

项目数据库已确定为 **MySQL 8.x**，`spec/` 规范体系与 `docs/` 项目综述文档在此项上已达成一致。
数据库设计、建表语句、字段类型、索引等均按 MySQL 8 编写，详见[数据库设计规范](数据库设计规范.md)。

若后续需迁移至达梦、PostgreSQL 等其他数据库，需同步修订以下内容：

- [数据库设计规范](数据库设计规范.md)：数据类型对照表、主键生成函数、保留字清单、`ON UPDATE` 语法
- [数据字典规范](数据字典规范.md)：建表语句与示例 SQL
- [数据模型规范](数据模型规范.md)：字段默认值与类型映射
- 本文的数据库一行
