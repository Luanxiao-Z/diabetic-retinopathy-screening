# 模型卡（Model Card）

本文件描述糖尿病视网膜病变（DR）筛查模型的训练数据、性能、适用边界与伦理考量，
供使用者判断该模型能否用于其场景。**本模型不是医疗器械，未经过临床验证或监管审批。**

## 一、模型概览

| 项 | 内容 |
| --- | --- |
| 任务 | 眼底图像 DR 五级分类（ICDR 分级标准） |
| 架构 | MobileNetV3-Small（ImageNet 预训练骨干 + 5 类分类头） |
| 输入 | RGB 眼底图像，224 × 224 像素 |
| 输出 | 五类 softmax 概率（LEVEL_0 ~ LEVEL_4）、归一化预测熵、Grad-CAM 热力图 |
| 参数规模 | 约 2.5 M（骨干为 small 变体，权重文件约 5.9 MB） |
| 框架 | PyTorch 2.14（cu130 / CPU 均可） |
| 版本标识 | `aptos2019-mobilenetv3s-1.0.0` |
| 权重路径 | `model-service/models/best_model.pth`（随仓库分发） |

### 分级定义

| 等级 | 名称 | 临床含义 | 转诊建议 |
| --- | --- | --- | --- |
| LEVEL_0 | 无 DR / 正常 | 无明显病变 | REVIEW（定期复查） |
| LEVEL_1 | 轻度 NPDR | 仅微动脉瘤 | REVIEW（定期复查） |
| LEVEL_2 | 中度 NPDR | 出血、硬性渗出等 | CLINIC（建议就诊） |
| LEVEL_3 | 重度 NPDR | 四个象限广泛出血、静脉串珠等 | REFERRAL（转诊） |
| LEVEL_4 | 增殖期 PDR | 新生血管、玻璃体积血等 | REFERRAL（转诊） |

## 二、训练数据

| 项 | 内容 |
| --- | --- |
| 数据集 | APTOS 2019 Blindness Detection（Kaggle） |
| 来源 | 印度 Aravind Eye Hospital 提供的眼底影像 |
| 使用版本 | `sovitrath` 发布的 224×224 预处理版（已裁去黑边） |
| 样本量 | 3662 张 |
| 划分方式 | 分层抽样 8:1:1（训练 / 验证 / 测试），随机种子 42 |
| 类别分布 | 无 DR 49.3%、轻度 10.1%、中度 27.3%、重度 5.3%、增殖期 8.1% |

**类别不均衡处理**：训练集最大/最小类相差 9.4 倍，采用平方根重采样（`--resample sqrt`）
在采样层缓解，验证/测试集保持原始分布以保证指标可比。三个随机种子的重复实验显示
`sqrt` 策略在准确率与宏平均 F1 上均优于基线且方差更小。

> 训练数据仅覆盖单一人群来源（印度），未包含中国人群样本；跨人群泛化能力未经验证，
> 这是本模型最重要的数据局限。

## 三、性能

### 测试集指标（367 张）

| 指标 | 数值 |
| --- | --- |
| 准确率 | 0.8229 |
| 宏平均 F1 | 0.6528 |
| 最佳验证轮次 | 第 29–30 轮（更多轮次会过拟合） |

### 重复实验对比（3 个种子，均值 ± 标准差）

| 配置 | 准确率 | 宏平均 F1 | 重度 NPDR F1 |
| --- | --- | --- | --- |
| 不重采样 | 0.8056 ± 0.0134 | 0.6450 ± 0.0260 | 0.3502 ± 0.020 |
| **sqrt（现行）** | **0.8193 ± 0.0093** | **0.6518 ± 0.0167** | 0.3671 ± 0.093 |
| oversample | 0.8002 ± 0.0072 | 0.6379 ± 0.0176 | 0.3965 ± 0.089 |

### 不确定性复核机制

模型除分级外输出归一化预测熵（0 完全确定 ~ 1 完全不确定），用于识别需人工复核的结果：

- 现行阈值 **0.15**：触发率 24.5%，覆盖 53.1% 的错分样本
- 对比“置信度 < 0.70”：仅触发 8.7%、覆盖 20.3% 的错分样本——深度模型置信度普遍饱和，故不采用置信度作判据

## 四、局限与已知风险

1. **少数类性能弱**：重度 NPDR 在测试集仅 20 张，F1 约 0.37，且标准差（±0.09）大于重采样带来的提升，
   无法断言该项稳定改善。
2. **高置信度错误无法识别**：约 23% 的错分样本熵低于 0.05，任何基于输出分布的不确定性指标都识别不出来。
3. **单一数据来源**：仅在 APTOS（印度人群）上训练，未验证跨设备、跨人群、跨拍摄条件的稳健性。
4. **图像质量依赖**：输入需为已裁去黑边、光照基本正常的眼底图；含失焦、曝光异常的影像不在训练分布内。
5. **二分类式转诊简化**：转诊建议由分级映射而来（LEVEL_3/4 → 转诊），未纳入黄斑水肿、病程等临床因素。
6. **阈值与模型绑定**：更换权重后必须重新标定复核阈值，否则复核机制的有效性下降。

## 五、预期用途与禁止用途

**预期**：教学演示、科研实验、工程实践参考；作为基层筛查流程中“是否需要转诊”的辅助提示。

**禁止**：作为独立诊断依据；替代执业医师判断；直接用于临床决策、医保结算、保险核保；
在未经本地数据验证与监管审批的情况下部署到真实诊疗流程。

## 六、伦理与隐私

- 训练数据来自公开竞赛数据集，不含可识别个人身份的信息；仓库内不含真实患者影像。
- 推理服务仅处理上传的影像，影像存放于部署方自有的私有对象存储桶，预签名链接 30 分钟有效。
- 模型可能对不同人群、不同设备的表现不一致，部署方应在目标人群上做前置验证并留存评估记录。

## 七、复现与再训练

```bash
cd model-service
python -m training.train --data-root ../datasets/aptos2019_224x224 \
  --epochs 30 --batch-size 32 --lr 3e-4 --resample sqrt --weight-scheme none
```

训练完成后导出 `models/best_model.pth` 与 `models/train_metrics.json`，推理服务零代码切换。
**更换模型后必须重新标定人工复核阈值**（见 README「十二、模型说明」）。
