## 目录结构说明

| 目录 | 说明 | 参考规范 |
| --- | --- | --- |
| `backend/` | Java 21 / Spring Boot 多模块工程 | [后端应用目录规划](../backend/后端应用目录规划.md) |
| `frontend/web/` | Vue 3 + Vite PC 端应用，包管理器 Yarn | [前端PC端应用目录规划](../frontend/前端PC端应用目录规划.md) |
| `model-service/` | Python 推理服务，独立于后端部署 | [项目技术栈](../design/项目技术栈.md) |
| `docs/` | 项目文档与开发规范，统一维护位置 | [项目规则](项目规则.md) |
| `sql/init/` | 建表与字典初始化脚本，幂等可重复执行 | [数据库设计规范](../design/数据库设计规范.md) |
| `deploy/` | Docker Compose 编排与 Nginx 反向代理 | [项目技术栈](../design/项目技术栈.md) |
| `datasets/` | 训练数据集，体积大且不入库，需自行下载 | 根 `README.md` 第十一节 |

## 命名约定

- 顶层目录使用小写英文单词，不使用下划线与大写字母。
- Java 根包为 `cn.edu.fzu.drs`，模块名统一以 `drs-` 为前缀。
- 数据库脚本集中在 `sql/init/`，采用 `IF NOT EXISTS` 等幂等写法，可重复执行完成升级。
- 凭据一律通过环境变量注入，`deploy/.env` 与任何明文密钥均不得提交。
