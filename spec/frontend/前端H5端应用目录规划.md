# 前端H5移动端和小程序端目录结构

```text
frontend/                          # 前端代码根目录
└─ h5/                             # H5 移动端与小程序应用
    ├─ src/                        # 源代码根目录（uni-app Vue3 版）
    │   ├─ main.ts                 # 应用入口
    │   ├─ App.vue                 # 应用入口组件
    │   ├─ pages/                  # 页面文件
    │   │   ├─ exception/          # 异常页面（404、无权限）
    │   │   ├─ public/             # 公共页面（登录、关于）
    │   │   └─ {模块分类}/         # 业务页面，按模块分类分目录存放
    │   │      └─ {页面}.vue       # 页面
    │   ├─ components/             # 公共组件
    │   │   └─ {组件分类}/         # 按组件分类分目录存放
    │   ├─ apis/                   # API 接口定义（按业务模块划分）
    │   ├─ stores/                 # Pinia 状态管理
    │   ├─ utils/                  # 工具函数（http 封装、存储、权限判断）
    │   ├─ types/                  # TypeScript 类型定义
    │   ├─ config/                 # 应用配置（常量、枚举）
    │   ├─ hooks/                  # 组合式函数
    │   ├─ directives/             # 自定义指令（如 v-permission）
    │   ├─ mixins/                 # 混入文件（仅用于兼容历史代码，新代码使用 hooks）
    │   └─ static/                 # 静态资源（图片、字体）
    ├─ uni_modules/                # uni-app 插件模块
    │   └─ uv-ui-tools/            # UV-UI 工具集
    ├─ .hbuilderx/                 # HBuilderX 配置
    ├─ manifest.json               # 应用配置（AppID、权限、各平台设置）
    ├─ pages.json                  # 页面路由与窗口样式配置
    ├─ uni.scss                    # 全局样式变量
    ├─ vite.config.ts              # Vite 配置
    ├─ package.json                # 依赖配置
    ├─ tsconfig.json               # TypeScript 配置
    ├─ .eslintrc.cjs               # ESLint 配置
    └─ .prettierrc.cjs             # Prettier 配置
```

## 目录说明

| 目录 | 说明 |
| --- | --- |
| `src/pages/` | 页面文件；新增页面必须同步在 `pages.json` 注册 |
| `src/apis/` | 接口前缀统一为 `/api/v1`，禁止硬编码后端服务名 |
| `src/stores/` | Pinia Store，与 PC 端保持一致 |
| `src/utils/` | 请求封装、本地存储、权限判断工具 |
| `static/` | 静态资源，小程序端计入包体积，大图应使用 CDN |
| `uni_modules/` | 由 HBuilderX 插件市场导入，不手工修改 |
