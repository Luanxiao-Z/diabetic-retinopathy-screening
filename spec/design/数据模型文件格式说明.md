# 数据模型文件格式说明

- 数据模型基于JSON格式定义
- $表示json对象的根节点
- .表示json一个层级，例如：$.name表示根节点下的name字段
- \[]表示json数组，例如：$.dataTypeSupports\[0]表示dataTypeSupports数组中的第一个元素
- \[n]表示数组中的第n个元素，例如：$.dataTypeSupports\[0].id表示dataTypeSupports数组中的第一个元素的id字段

## 1、总体说明

| 名称      | JSON的KEY定位 | 取值   |
| ------- | ---------- | ---- |
| 项目总体名称  | $.name     | 字符串  |
| 项目的总体描述 | $.describe | 文本描述 |

UUID 为 32 位大写十六进制数，按 `8-4-4-4-12` 分为 5 段，含分隔符共 36 个字符，例如：

```
FC9790A7-36B8-4A48-8F9A-BC1042BCFE64
```

模型中所有 `id` 属性均为此类 UUID，且必须全局唯一。

## 2、数据库或编程语言定义

数据库或编程语言的数组定义: $.dataTypeSupports

每个dataTypeSupports定义了一个数据库或是编程语言对应的数据类型

每个dataTypeSupports对象字段定义如下表格:

| 名称     | JSON的KEY定位                    | 取值   |
| ------ | ----------------------------- | ---- |
| 类型定义标识 | $.dataTypeSupports\[n].id     | UUID |
| 类型定义编码 | $.dataTypeSupports\[n].defKey | 英文编码 |

## 3、基本数据类型定义

基本数据类型的数组定义: $.dataTypeMapping.mappings

每个mappings定义了一个基本数据类型，每个基本数据类型都对应一个UUID，用于唯一标识该基本数据类型。
一个基本数据类型，对应为不同的数据库的数据类型定义与不同的编程语言的数据类型定义的映射关系。

每个mappings对象字段定义如下表格:

| 名称           | JSON的KEY定位                             | 取值        |
| ------------ | -------------------------------------- | --------- |
| 基本数据类型ID     | $.dataTypeMapping.mappings\[n].id      | UUID      |
| 基本数据类型编码     | $.dataTypeMapping.mappings\[n].defKey  | 唯一英文字符串编码 |
| 基本数据类型名称     | $.dataTypeMapping.mappings\[n].defName | 中文名称      |
| 不同数据库的类型映射关系 | $.dataTypeMapping.mappings\[n].\[dbId] | 数据库类型编码   |

**dbId**表示数据库类型的dataTypeSupports数组成员对应的id属性

配置json示例:

```json
{
    "dataTypeMapping": {
        "mappings": [
            {
                "id": "FC9790A7-36B8-4A48-8F9A-BC1042BCFE64",
                "defKey": "string",
                "defName": "字串",
                "29D1CE08-4C35-4D2D-AAA9-23D93305B52E": "VARCHAR",
                "A4E23CB7-BB01-4BD1-9F71-F73F3E15A542": "VARCHAR2",
                "BFC87171-C74F-494A-B7C2-76B9C55FACC9": "VARCHAR",
                "DFBEC1DD-AA84-456E-BBF3-C95DD0DB2022": "VARCHAR",
                "89504F5D-94BF-4C9E-8B2E-44F37305FED5": "VARCHAR",
                "0BBCABA5-B8E4-41B0-B8E4-8F5EA6029307": "VARCHAR2",
                "77BD85E5-9D0D-4096-8427-CBA306FC9C6A": "VARCHAR",
                "B363BE0B-F852-49B8-9B2E-F6D2174DEAC1": "TEXT",
                "797A1496-D649-4261-89B4-544132EC3F36": "String",
                "A2EE7B4A-CE62-4290-B00C-B26C1BF18073": "String"
            }
        ]
    }
}
```

## 4、数据域类型定义

数据域类型的数组定义: $.domains

每个domains定义了一个数据域类型，用于统一表示表字段的数据类型

表字段引用同一数据域类型代表这些字段使用同一类基本数据类型定义，通过变更数据域类型的定义可以同时修改所以同类型的所有字段的数据类型定义，没有引用数据域类型的字段必须指定基本数据类型

每个domains对象字段定义如下表格:

| 名称        | JSON的KEY定位             | 取值                                                   |
| --------- | ---------------------- | ---------------------------------------------------- |
| 数据域标识     | $.domains\[n].id       | UUID                                                 |
| 数据域代码     | $.domains\[n].defKey   | 英文编码                                                 |
| 数据域名称     | $.domains\[n].defName  | 文本描述                                                 |
| 数据域类型     | $.domains\[n].applyFor | 基本数据类型的ID, 对应$.dataTypeMapping.mappings数组中的成员对象的id属性 |
| 数据域长度     | $.domains\[n].len      | 整数值                                                  |
| 数据域小数精度类型 | $.domains\[n].scale    | 整数值                                                  |

## 5、当前项目默认数据库类型

默认数据库指向：$.profile.default.db
可选取值为$.dataTypeSupports数组中定义的数据库类型结构的id

**本项目默认数据库为 MySQL**（$.dataTypeSupports 中 defKey 为 `MYSQL` 的成员，示例 id 为 `29D1CE08-4C35-4D2D-AAA9-23D93305B52E`）。
默认数据库决定了新建表字段的`type`取值与导出 DDL 的目标方言，导出脚本按此生成 MySQL 语法（内联 COMMENT、DATETIME、ON UPDATE CURRENT_TIMESTAMP 等）。

示例如下：

```json
{
    "dataTypeSupports": [
      {
        "defKey": "MYSQL",
        "id": "29D1CE08-4C35-4D2D-AAA9-23D93305B52E"
      }
    ],
    "profile" : {
        "default": {
            "db": "29D1CE08-4C35-4D2D-AAA9-23D93305B52E"
        }
    }
}
```

## 6、表字段列定义

表字段列的数组定义：$.headers

每个headers成员代表一个表字段列。每次新建表都要从此数组复制字段列定义。

每个headers成员定义如下表格:

| 名称      | JSON的KEY定位                | 取值                  |
| ------- | ------------------------- | ------------------- |
| 字段代码    | $.headers\[n].refKey      | 字符串                 |
| 字段名称    | $.headers\[n].value       | 字符串                 |
| 是否启用    | $.headers\[n].enable      | 布尔值, 可选，未定义则默认为true |
| 是否冻结    | $.headers\[n].freeze      | 布尔值, 默认为false       |
| 隐藏在关系图中 | $.headers\[n].hideInGraph | 布尔值, 可选，未定义时以工具默认值为准 |

```json
{
"headers": [
  {
    "refKey": "defKey",
    "value": "字段代码",
    "freeze": false,
    "hideInGraph": false
  },
  {
    "refKey": "isStandard",
    "value": "标准字段",
    "enable": false,
    "freeze": false,
    "hideInGraph": true
  }
]
}
```

## 7、标准字段库定义

标准字段库的数组定义：$.standardFields

每个standardFields成员代表一个标准字段库，用于表示某一类标准字段的集合，例如：默认表字段、默认字典字段等。

每个standardFields成员定义如下表格:

| 名称        | JSON的KEY定位                 | 取值   |
| --------- | -------------------------- | ---- |
| 标准字段库标识   | standardFields\[n].id      | UUID |
| 标准字段库编码   | standardFields\[n].defKey  | 字符串  |
| 标准字段库中文名称 | standardFields\[n].defName | 字符串  |
| 标准字段数组    | standardFields\[n].fields  | 数组   |

每个fields成员定义如下表格:

| 名称          | JSON的KEY定位                                  | 取值                                                   |
| ----------- | ------------------------------------------- | ---------------------------------------------------- |
| 标准字段标识      | standardFields\[n].fields\[m].id            | UUID                                                 |
| 标准字段编码      | standardFields\[n].fields\[m].defKey        | 字符串                                                  |
| 标准字段中文名称    | standardFields\[n].fields\[m].defName       | 字符串                                                  |
| 标准字段数据字典    | standardFields\[n].fields\[m].refDict       | 数据字典的ID，对应$.dicts数组中成员对象的id属性                        |
| 标准字段数据域     | standardFields\[n].fields\[m].domain        | 数据域的ID，对应$.domains数组中成员对象的id属性                       |
| 标准字段基本数据类型  | standardFields\[n].fields\[m].baseType      | 基本数据类型的ID, 对应$.dataTypeMapping.mappings数组中的成员对象的id属性 |
| 标准字段长度      | standardFields\[n].fields\[m].len           | 整数值                                                  |
| 标准字段小数精度类型  | standardFields\[n].fields\[m].scale         | 整数值                                                  |
| 标准字段是否主键    | standardFields\[n].fields\[m].primaryKey    | 布尔值                                                  |
| 标准字段是否为空    | standardFields\[n].fields\[m].notNull       | 布尔值                                                  |
| 标准字段是否自增    | standardFields\[n].fields\[m].autoIncrement | 布尔值                                                  |
| 标准字段默认值     | standardFields\[n].fields\[m].defaultValue  | 字符串                                                  |
| 标准字段备注      | standardFields\[n].fields\[m].comment       | 文本字符串                                                |
| 标准字段是否隐藏在图中 | standardFields\[n].fields\[m].hideInGraph   | 布尔值                                                  |
| 缺省字段扩展属性    | standardFields\[n].fields\[m].extProps      | 对象                                                   |

示例格式如下：

{

## 9、新建表缺省属性

缺省属性：$.profile.default.entityInitProperties

该节点用于定义新建表时自动填充的表级属性集合（如表注释模板、字符集、存储参数、代码生成命名空间等），
结构为对象。当前项目未启用该特性，取值保留为空对象：

```json
{
  "profile": {
    "default": {
      "entityInitProperties": {}
    }
  }
}
```

## 10、数据字典定义

数据字典的数组定义：$.dicts

每个dicts定义了一个数据字典，用于表示某一类可选的取值，例如：状态的可选值，支付方式的可选值。
一个数据字典域的取值可能影响另一个数据字典域的取值。例如：应用类型的可选值可能影响支付方式的可选值。

每个dicts成员定义如下表格:

| 名称         | JSON的KEY定位        | 取值         |
| ---------- | ----------------- | ---------- |
| 数据字典标识     | dicts\[n].id      | UUID       |
| 数据字典编码     | dicts\[n].defKey  | 字符串        |
| 数据字典中文名称   | dicts\[n].defName | 字符串        |
| 数据字典排序     | dicts\[n].sort    | 字符串，按字符串排序 |
| 数据字典备注     | dicts\[n].intro   | 字符串        |
| 数据字典明细成员数组 | dicts\[n].items   | 数组         |

每个items成员定义如下表格:

| 名称         | JSON的KEY定位                    | 取值         |
| ---------- | ----------------------------- | ---------- |
| 数据字典明细标识   | dicts\[n].items\[m].id        | UUID       |
| 数据字典明细编码   | dicts\[n].items\[m].defKey    | 字符串        |
| 数据字典明细中文名称 | dicts\[n].items\[m].defName   | 字符串        |
| 数据字典明细排序   | dicts\[n].items\[m].sort      | 字符串，按字符串排序 |
| 数据字典明细父编码  | dicts\[n].items\[m].parentKey | 字符串        |
| 数据字典明细备注   | dicts\[n].items\[m].intro     | 字符串        |
| 数据字典明细是否启用 | dicts\[n].items\[m].enabled   | 布尔值        |

| 数据字典明细属性2  | dicts\[n].items\[m].attr2     | 字符串        |
| 数据字典明细属性3  | dicts\[n].items\[m].attr3     | 字符串        |

## 11、数据字典导出语句模板

数据字典导出语句需要适配当前项目内数据字典主键和数据字典明细表的实体表定义。

**占位符与本项目的对应关系**（以[数据字典规范](数据字典规范.md)中的表结构为准）：

| 模板占位符 | 实际对象 | 说明 |
| --- | --- | --- |
| {字典主表表名} | `sys_dict_domain` | 字典域表 |
| {字典域编码字段名} | `domain_code` | 字典域编码 |
| {字典域中文名称字段名} | `domain_name` | 字典域名称 |
| {字典域备注字段名} | `domain_desc` | 字典域描述 |
| {字典明细表表名} | `sys_dict_item` | 字典明细表 |
| {字典明细表字典域编码字段名} | `domain_code` | 所属字典域编码 |
| {字典明细表字典明细编码字段名} | `item_code` | 字典项编码 |
| {字典明细表字典明细名称字段名} | `item_name` | 字典项名称 |
| {字典明细表父编码字段名} | `parent_code` | 父级字典项编码，顶层为 NULL |
| {字典明细表排序字段名} | `sort` | 排序号 |
| {字典明细表备注字段名} | `item_desc` | 字典项描述 |
| {字典明细表记录状态字段名} | `state` | 记录状态，启用=1，禁用=0 |

> 注意：模板中 `parent_code` 为空字符串时应导出为 `NULL`，需在 dot.js 模板中做空值处理。

模板数组定义: $.codeTemplates

每一个codeTemplates数组成员定义了一个编码模板，每个模板对象都有一个type属性，用于指定模板的类型。

模板对象type属性如果取值为dbDDL，则表示模板是数据库DDL语句模板

格式如下:

```json
{
"codeTemplates": [
    {
        "type": "dbDDL",
        "applyFor": "dictSQLTemplate",
        "content": "导出模板"
    }
  ]
}
```

在数据库DDL语句模板中，applyFor属性为dictSQLTemplate的是数据字典导出语句模板，对应的content属性为导出语句模板的内容，内容需符合[dot.js开源库](https://github.com/olado/doT)的脚本语法格式。

数据字典导出语句模板示例如下:

```sql
/* 删除字典明细表[{{=it.dict.defKey}}-{{=it.dict.defName}}] */
DELETE FROM {字典明细表表名} WHERE {字典域编码字段名} = '{{=it.dict.defKey}}';
/* 删除字典主表[{{=it.dict.defKey}}-{{=it.dict.defName}}] */
DELETE FROM {字典主表表名} WHERE {字典域编码字段名} = '{{=it.dict.defKey}}';

/* 插入字典主表[{{=it.dict.defKey}}-{{=it.dict.defName}}] */
INSERT INTO {字典主表表名}(id,{字典域编码字段名},{字典域中文名称字段名},{字典域备注字段名}) VALUES(REPLACE(UUID(), '-', ''), '{{=it.dict.defKey}}','{{=it.dict.defName}}','{{=it.dict.intro}}');
/* 插入字典明细表[{{=it.dict.defKey}}-{{=it.dict.defName}}] */
{{~it.dict.items:item:index}}
INSERT INTO {字典明细表表名}(id,{字典明细表字典域编码字段名},{字典明细表字典明细编码字段名},{字典明细表字典明细名称字段名},{字典明细表父编码字段名},{字典明细表排序字段名},{字典明细表备注字段名},{字典明细表记录状态字段名}) VALUES(REPLACE(UUID(), '-', ''), '{{=it.dict.defKey}}','{{=item.defKey}}','{{=item.defName}}','{{=item.parentKey}}','{{=item.sort}}','{{=item.intro}}',{{?item.enabled}}1{{??}}0{{?}});
{{~}}

```

**其中item.enabled表示数据字典明细是否启用。对应的dot.js语法生成脚本为{{?item.enabled}}`启用值`{{??}}`禁用值`{{?}}**
**其中item.parentKey为可选参数，表示数据字典明细的父明细编码。**
